# BLAME.GG — разбор матча Dota 2

Статический сайт без бэкенда: HTML + CSS + JS, данные берутся из открытого OpenDota API.
Сделан по мотивам who-ruined, переработаны модель оценки, функции и дизайн.

## Запуск локально

```bash
npx -y http-server@14.1.1 blame-gg -p 5180 -c-1
```

Открыть http://localhost:5180. Прямая ссылка на матч: `?match=<id>`, на игрока: `?player=<account_id>`.

## BLAME+ (монетизация)

Бесплатно доступен полный разбор любого матча. В BLAME+ входят досье на любого игрока, рейтинг пати и карточки без плашки.

- Покупка — в Telegram-боте [@blamedota_bot](https://t.me/blamedota_bot) за Telegram Stars или через Boosty (заявка `/boosty`, выдача `/grant`).
- Доступ — **личный код** из бота (`/code`). Сервер (папка `blame-gg-bot`, Cloudflare Workers + D1) привязывает код к одному браузеру. Тот же код в другом браузере → «Код уже используется другим пользователем».
- Кнопка в боте открывает сайт с `?redeem=<код>`: код активируется сам.
- Сайт перепроверяет код раз в 6 часов: отозванный или перенесённый код отключается.
- Адрес сервера — `apiUrl` в `config.js`.
- Аналитика: ID Яндекс Метрики в `config.js`. Цели: `analyze_match`, `open_story`, `share_png`, `share_link`, `dossier_open`, `party_add`, `party_run`, `paywall_view`, `paywall_boosty`, `code_success`, `code_fail`, `donate_click`.
- Прямые ссылки: `?dossier=<account_id>`, `?party=1`, `?redeem=<код>`.

## Деплой (бесплатно)

GitHub Pages: залить содержимое папки в репозиторий, затем Settings → Pages → Deploy from branch.
Подойдут также Netlify и Cloudflare Pages: перетащить папку, сборка не нужна.

## Что изменилось относительно оригинала

**Модель**
- Метрики сравниваются с перцентилями OpenDota по конкретному герою (`benchmarks`), а не с захардкоженными «GPM 520 для керри».
- Позиции определяются по линиям, а без данных о линиях — по фарму, XPM и ролям героя. В оригинале Axe-оффлейнер попадал в Pos 4.
- Позицию можно поправить вручную: индекс пересчитается сразу, правка сохранится для этого матча.
- Индекс вины разложен на 6 факторов (фарм, опыт, драки, смерти, строения, помощь команде) с весами для каждой позиции, и видно, сколько очков дал каждый фактор.
- Уверенность считается по отрыву от следующего игрока, наличию бенчмарков и разобранного реплея.
- Исправлены баги оригинала: драки читались по `player_slot` вместо индекса игрока (у Тьмы ломалось), предметы искались не по тому ключу.

**Функции**
- Поиск игрока по нику, Steam ID, Steam64 или ссылке на профиль, затем выбор матча из последних 20.
- Кнопка «Разобрать реплей», если матч не распарсен: запрос в OpenDota и автообновление по готовности.
- Интерактивный график золота и опыта с маркерами драк и Рошана, переломные драки, лента событий.
- Подсказка «игра была выигрышной»: максимальный перевес проигравших и минута, когда он был потерян.
- «Мой разбор»: радар-профиль против типичной игры на герое, что подтянуть (с конкретными советами) и что получилось.
- Запоминание своего аккаунта, история разборов, копирование итога и PNG-картинка для шеринга.

**Дизайн**
- Тёмная киберспортивная тема, вкладки вместо одной длинной ленты, адаптив под телефон.
